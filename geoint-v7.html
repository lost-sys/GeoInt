IA & clés API

Les IA sont essayées dans cet ordre : Gemini → Claude → OpenAI → Groq → OpenRouter → perso. En mode économique, GeoInt utilise l'IA économique du serveur : aucune clé API n'est demandée à l'utilisateur.

1 · Gemini obtenir une clé

2 · Claude créer une clé API

Anthropic peut offrir quelques crédits de test aux nouveaux comptes ; l’API nécessite ensuite des crédits payants. La clé reste dans ce navigateur.

3 · OpenAI créer une clé API

La clé API OpenAI est distincte d’un abonnement ChatGPT. Chaque utilisateur configure sa clé dans son navigateur.

4 · Groq (gratuit) obtenir une clé

5 · OpenRouter (modèles :free) obtenir une clé

6 · Autres IA compatibles OpenAI (jusqu'à 3)

Clés stockées uniquement dans le localStorage de ce navigateur. Ne les écris jamais en dur dans le fichier.
