IA & clés API

Les IA sont essayées dans cet ordre : Gemini → Groq → OpenRouter → perso. En mode économique, GeoInt utilise l'IA économique du serveur : aucune clé API n'est demandée à l'utilisateur.

1 · Gemini obtenir une clé

2 · Groq (gratuit) obtenir une clé

3 · OpenRouter (modèles :free) obtenir une clé

4 · Autres IA compatibles OpenAI (jusqu'à 3)

Clés stockées uniquement dans le localStorage de ce navigateur. Ne les écris jamais en dur dans le fichier.
